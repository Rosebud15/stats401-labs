Lab 5: Interactive Urban Transit Network

This page represents the same synthetic 50-station transit network in two ways: an interactive force-directed node-link diagram and an adjacency matrix.

1. Dataset Description

The network contains 50 stations and 50 bidirectional direct connections. Station attributes are district, daily passengers, and station type. Route attributes are travel time and route type.

2. Node-Link Visualization

Drag stations to reposition them. Hover a station or route to isolate its local structure.

Node-Link Design Description

District is mapped to node color because district is categorical, making it easy to identify stations from the same geographic area. Daily passenger volume is mapped to node size so heavily used stations stand out immediately, while station type is encoded with shape so local, transfer, and terminal stations remain distinguishable without introducing additional colors. Route type is represented with line texture—solid, dashed, or dotted—rather than color, which avoids confusion with the district color encoding. Travel time is mapped to link width, with thicker links representing longer direct travel times. Interaction further supports exploration: dragging helps separate overlapping nodes, hover highlighting isolates a station's neighbors and incident routes, and tooltips provide exact station and route attributes without permanently crowding the visualization.

3. Adjacency Matrix

Hover a cell to inspect a station pair. Connected cells are colored by route type and darken with travel time.

Matrix Design Description

The adjacency matrix represents stations as rows and columns, with a filled cell indicating a direct connection between two stations. Travel time is encoded with cell opacity, so longer travel times appear more strongly, while route type is represented using cell texture or pattern, such as solid fill, diagonal stripes, or dots. This keeps the route-type encoding consistent with the line textures used in the node-link view while avoiding competition with district colors. Station labels and small row/column glyphs preserve important node information: color represents district, shape represents station type, and glyph size represents daily passenger volume. Rows and columns are ordered by district, then station type, and then passenger volume, which groups similar stations together and makes district-level blocks, station roles, and repeated connection patterns easier to identify. This preserves much of the node context from the node-link visualization while making dense connection patterns easier to compare systematically.

4. Network Questions and Findings

1. Which stations appear central in the network?

Answerability: Partially

Most useful visualization: Node-Link

Connections are represented by links between stations. Stations with several visible links, especially those joining different portions of the network, appear more central. Hover highlighting also makes a station's immediate neighbors easier to identify.
However, there is no single dominant hub. The highest visible degree is only about three connections. Stations 4, 7, 10, 13, 16, 18, 21, 23, 25, 29, 31, 33, 34, and 38 have relatively high connectivity. In the node-link layout, stations such as 7, 18, 31, and 34 appear particularly important because they connect multiple nearby segments. By contrast, stations such as 42 and 49 are visibly isolated, so they are clearly not central.

2. Which districts are strongly connected to one another?

Answerability: Well

Most useful visualization: Adjacency matrix

Stations are ordered by district → station type → passenger volume, and station labels are colored by district. This creates clear district blocks in the matrix. A greater concentration of filled cells between two district blocks indicates stronger inter-district connectivity.
The strongest connection is between the South and East districts, with about 11 direct connections. Central-North and East-West are also strongly connected, with about 9 connections each. Central-West and North-South also show substantial connectivity, with about 8 connections each. Some district pairs have very few or no direct links, so the network is not uniformly connected across districts.

3. Where are transfer or terminal stations located in the topology?

Answerability: Well

Most useful visualization: Both, but the node-link visualization is more useful for understanding their topological positions.

Station type is encoded by shape: circles are local stations, squares are transfer stations, and triangles are terminal stations. The node-link graph shows where those shapes fall within the network, while the matrix groups them systematically within each district.
Transfer and terminal stations are distributed throughout the network rather than forming one separate cluster. Several terminals, such as 31, 34, and 25, are actually fairly well connected and sit within the main network rather than only at endpoints. However, some terminals such as 46, 43, and 49 are isolated. Transfer stations generally appear along connected chains; for example, 23, 29, and 38 each have several connections, while 44, 47, and 50 are much more peripheral.

4. Which stations have high passenger volume?

Answerability: Well

Most useful visualization: Both, although the node-link visualization makes the differences easiest to see

Passenger volume is encoded by node size. Larger station symbols indicate higher daily passenger volume. The adjacency matrix also repeats these differently sized station symbols along its axes.
The highest-volume stations are represented by the largest symbols. Some of the most visually prominent examples include Station 46, 41, and 36 in Central; 37, 47, and 42 in North; 43, 38, and 48 in South; 49, 44, and 39 in East; and 40, 50, and 45 in West. Stations such as 49, 40, 46, 37, and 43 are especially easy to identify because of their large symbols.

5. Where are the longest direct travel-time connections?

Answerability: Well

Most useful visualization: Both

In the node-link visualization, thicker links represent longer travel times. In the adjacency matrix, darker/more opaque cells represent longer travel times. Using both views makes unusually long links relatively easy to confirm.
The Station 31-Station 7 connection is one of the clearest longest direct connections; it appears as an especially thick Express link and a very dark corresponding matrix cell. Other relatively long connections include Station 18-Station 34, Station 29-Station 30, Station 23-Station 4, and Station 18-Station 19. These stand out through either high opacity in the matrix or thick lines in the node-link graph

6. Are particular route types concentrated in particular parts of the network?

Answerability: Well

Most useful visualization: Adjacency matrix, with the node-link visualization as supporting evidence.

Route type is encoded by color: blue for Metro, orange for Express, and gray for Shuttle. Because the matrix groups stations by district, it is easy to see whether one color dominates a particular district-to-district block.
There is no strong overall concentration of a single route type in one part of the network. Metro, Express, and Shuttle links are fairly mixed across the major district-pair blocks. There are some mild tendencies, for example, Central-North and East-West contain several Express routes, but these same regions also contain Metro and Shuttle routes. The South-East block, which has the largest number of connections overall, contains a mixture of all three route types rather than being dominated by one. Therefore, route type appears relatively dispersed across the network rather than geographically or topologically segregated.

Lab 3: Web Data Acquisition

Dataset Description

This dataset contains information about 1,000 books collected from Books to Scrape, a website designed for web scraping practice.

Data source: Books to Scrape

Acquisition method: HTML scraping using Python, as well as the requests, BeautifulSoup, and pandas libraries.

Records collected: 1,000

Each record contains a book ID, title, price in British pounds, star rating, and availability.

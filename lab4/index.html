Lab 4: Cleaning Web Data for Visualization

RoBERTa sentiment across major U.S. airlines

Tweet Sentiment by Airline

Each bar shows the proportion of tweets classified as negative, neutral, or positive by the RoBERTa model. Airlines are ordered from highest to lowest average sentiment score.

Analysis

I used the Twitter US Airline Sentiment dataset (source), which contains tweets about six major U.S. airlines collected in February 2015. Although the source dataset includes human sentiment labels, I did not use those labels to create this chart; instead, I recalculated sentiment from tweet text with the cardiffnlp/twitter-roberta-base-sentiment-latest model. During cleaning, I removed rows without usable tweet text or airline information, removed duplicate tweet IDs, normalized whitespace, converted retweet counts to numeric values, and parsed tweet timestamps. RoBERTa produced negative, neutral, and positive probabilities for each tweet, and sentiment_score was calculated as P(positive) minus P(negative). The visualization shows the proportion of model-predicted sentiment classes for each airline and orders airlines by average sentiment score.
